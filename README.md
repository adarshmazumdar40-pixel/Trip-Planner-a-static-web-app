# Trip Planner — Static AI-Style Itinerary Generator

Trip Planner is a polished client-side web prototype that creates a day-wise itinerary from destination, dates, vibe, and interest tags — no backend, no API key, just a local JavaScript rules engine.

## Features
- Form-based trip setup (destination, start/end date, vibe, interests)
- Rule-driven day plans with morning/afternoon/evening slots
- Mock venue dataset with cost bands (₹ / ₹₹ / ₹₹₹)
- Day-tab UI with smooth transitions for quick switching
- Graceful empty and loading states
- Mobile responsive layout

## Tech Stack
- HTML (single page)
- CSS (responsive + animated UI)
- Vanilla JavaScript (rules engine + rendering)
